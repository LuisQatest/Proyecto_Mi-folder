Portafolio Web Personal
Este proyecto es mi portafolio web personal, desarrollado desde cero durante mi formación en Desarrollo Front-End en Talento Tech.

El sitio tiene como objetivo presentar mi perfil, mi trayectoria, mis habilidades técnicas y los proyectos que he realizado.

Tecnologías Utilizadas
HTML: Maquetado semántico.

CSS: Estilos estructurados con metodología BEM.

Estructura del Sitio
Sobre mí: Presentación personal y resumen de habilidades.

Trayectoria: Tabla con mi formación y experiencia.

Proyectos: Tarjetas con mis trabajos y enlaces a sus repositorios.

Contacto: Formulario para el envío de mensajes.
